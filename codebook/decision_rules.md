# Decision Rules

1. Code the document that is actually named in the corpus manifest, not a
   related webpage unless the manifest explicitly defines the webpage as the
   source.
2. Prefer explicit controls, requirements, attack descriptions, mitigations,
   assessment criteria, or assurance requirements over broad narrative claims.
3. A generic lifecycle statement is insufficient for layer-specific coverage.
4. If a control clearly spans two layers, record evidence for both layers only
   when the source substantively addresses both.
5. Do not use the proposed seven-layer model to manufacture coverage that the
   source does not state.
6. If the correct code remains uncertain, record `L` confidence and explain the
   ambiguity rather than forcing a high-confidence decision.
7. Keep initial coder decisions immutable; put changes after disagreement into
   the adjudication file.
